# Changelog

## [1.1.0] - 2026-09-27
### Adicionado
- Modo de alto contraste com preferência salva e suporte a prefers-contrast.
- Build de produção com minificação e otimização de imagens.
- Deploy automático no GitHub Pages via GitHub Actions.

### Corrigido
- Link "Pular para o conteúdo" e resumo de erros que trocavam a rota da SPA.
- Contraste do indicador de foco (1,79:1 para 10,87:1).
- Modal sem foco preso, notificações sem tempo ajustável e layout shift no carregamento.

## [1.0.0] - 2026-09-26
### Adicionado
- SPA com navegação por hash e páginas de início, projetos e cadastro.
- Design system responsivo com Grid de 12 colunas e cinco breakpoints.
- Formulário com máscaras, validação de CPF e persistência no localStorage.
- Preenchimento de endereço pelo CEP (ViaCEP).
- Simulador de impacto da doação com Alpine.js.
